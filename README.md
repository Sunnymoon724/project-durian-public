# Project Durian

Unreal Engine 5.8과 C++로 만드는 3D 물리 능력 퍼즐 액션 데모입니다.

젤다의 전설: 야생의 숨결에 나오는 사당을 참고해 퍼즐 사당 5개와 전투 사당 1개를 구현합니다. 플레이어는 중앙 허브에서 사당을 선택하고, 자력·얼음 생성·시간 정지·원격 폭탄 능력으로 퍼즐을 해결합니다.

## 요구 사항

- Unreal Engine 5.8
- Visual Studio 2022 및 Game development with C++

## 프로젝트 열기

1. Unreal Engine 5.8과 Visual Studio 2022를 설치합니다.
2. [Durian/Durian.uproject](Durian/Durian.uproject)을 Unreal Editor로 엽니다.
3. C++ 모듈을 빌드한 뒤 에디터 시작 맵에서 테스트합니다.

## 폴더 구성

- `Durian/` — Unreal Engine 프로젝트
- `Durian/Source/` — C++ 게임 모듈
- `Durian/Content/` — 맵, Blueprint, 입력 에셋과 기타 Unreal 에셋
- `Durian/Config/` — 프로젝트 설정
- `Documents/` — 게임 설계와 제작 계획 문서
- `Chronicle/` — Docusaurus 기반 개발 기록
