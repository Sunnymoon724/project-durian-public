# Project Durian

Unreal Engine 5.8로 제작 중인 C++ 게임 프로젝트입니다. 현재 횡스크롤, 플랫폼, 전투 게임플레이 변형을 포함합니다.

## 요구 사항

- Unreal Engine 5.8
- Visual Studio 2022 (Game development with C++)

## 프로젝트 열기

1. Unreal Engine 5.8을 설치합니다.
2. [Sources/Project_Durian.uproject](Sources/Project_Durian.uproject)를 열어 프로젝트 파일을 생성합니다.
3. Unreal Editor에서 프로젝트를 열거나, 생성된 솔루션을 빌드합니다.

## 디렉터리 구성

- `Sources/` — Unreal 프로젝트와 C++ 소스 코드
- `Sources/Source/Project_Durian/Variant_SideScrolling/` — 횡스크롤 게임플레이
- `Sources/Source/Project_Durian/Variant_Platforming/` — 플랫폼 게임플레이
- `Sources/Source/Project_Durian/Variant_Combat/` — 전투 게임플레이
