# 게임 규칙

## 공통 규칙

- 플레이어는 한 번에 하나의 능력만 선택한다.
- 화면 중앙의 대상 후보는 사용 가능 여부가 시각적으로 구분된다.
- 능력 취소, 사망, 거리 이탈과 레벨 재시작은 실행 상태를 안전하게 종료한다.
- 각 능력은 한 사당에서 기본 사용법을 가르치고 짧은 응용을 제공한다.

## 자력

### 역할

금속으로 지정된 물리 오브젝트를 원거리에서 잡아 이동하고 놓는다.

### 기본 흐름

1. 자력을 선택한다.
2. 유효한 금속 물체를 조준한다.
3. 물체를 잡고 카메라 앞 목표 위치로 이동한다.
4. 마우스 휠로 거리를 조절한다.
5. 원하는 위치에 놓거나 취소한다.

### 제한

- 동시에 한 물체만 조작한다.
- 최소·최대 거리와 벽 가림을 검사한다.
- 직접 회전은 미결정이며 초안 범위에서는 요구하지 않는다.

## 얼음 생성

### 역할

유효한 수면 위에 충돌 가능한 얼음 블록을 생성해 발판이나 장애물로 사용한다.

### 규칙 초안

- 지정된 수면 영역에서만 생성한다.
- 동시에 유지 가능한 블록은 1~2개다.
- 생성 불가능한 위치는 사용 전에 피드백한다.
- 한도를 넘으면 가장 오래된 블록을 제거할지, 새 생성을 거부할지 결정이 필요하다.

## 시간 정지

### 역할

물리 오브젝트를 잠시 정지하고, 정지 중 받은 힘을 축적해 해제 시 한 번에 적용한다.

### 규칙 초안

- 지정된 대상만 정지한다.
- 정지 시간과 축적 가능한 최대 힘을 제한한다.
- 축적 방향과 강도를 플레이어가 읽을 수 있게 표시한다.
- 해제 뒤 발사된 오브젝트가 목표 판정을 안정적으로 발생시켜야 한다.

## 원격 폭탄

### 역할

폭탄을 하나 생성하고 원하는 시점에 기폭해 물리 힘, 피해 또는 파괴 반응을 일으킨다.

### 규칙 초안

- 동시에 하나만 유지한다.
- 첫 입력으로 생성하고 후속 입력으로 기폭한다.
- 폭발 대상은 힘을 받는 오브젝트, 피해 대상과 파괴 대상으로 구분한다.
- 플레이어 피해와 넉백 강도는 진행 차단이 생기지 않도록 제한한다.

## 능력별 확인이 필요한 값

| 능력 | 주요 조정값 |
| --- | --- |
| 자력 | 탐색 거리, 잡기 거리, 이동 속도, 감쇠, 질량 제한 |
| 얼음 | 최대 개수, 크기, 생성 거리, 제거 규칙 |
| 시간 정지 | 지속 시간, 최대 축적 힘, 타격당 축적량 |
| 폭탄 | 생성 거리, 폭발 반경, 힘, 피해, 재사용 시간 |
