# 요약

플레이어는 수면 위 유효한 위치에 얼음 블록을 생성해 발판 또는 물리적 지지대로 사용할 수 있다.

# 목표 및 의도

플레이어 약속: 수면 위 유효한 위치에 얼음 블록을 생성해 발판 또는 물리적 지지대로 사용한다.

# 게임 규칙

- 수면 영역 안에서만 생성한다.
- 생성 지점은 플레이어와 겹치거나 주요 오브젝트를 밀어내지 않아야 한다.
- 동시 유지 수는 1~2개다.
- 제한에 도달하면 새 생성 거부 또는 가장 오래된 블록 제거 중 하나를 확정한다.
- 재시작 시 생성 블록은 모두 제거한다.
- 피드백: 유효 위치는 투명한 미리보기로, 불가능한 위치는 다른 색·아이콘·짧은 효과로 구분한다.
