# 요약

자력 능력은 플레이어가 금속 물체를 조준해 잡아 이동시키고, 원하는 위치에 놓을 수 있도록 하는 기능입니다. 이를 통해 플레이어는 물리 기반 퍼즐을 풀거나 환경과 상호작용할 수 있습니다.

# 목표 및 의도

- 금속 물체를 직관적으로 제어하도록 설계
- 게임 내 물리 엔진을 활용한 다이나믹한 상호작용 제공
- 플레이어가 물체를 자유롭게 이동·놓을 수 있게 하여 창의적 플레이를 유도

# 게임 규칙

1. **대상 선택**  
   - 금속 태그 또는 자력 대상 컴포넌트가 있는 물체만 선택 가능  
   - 선택 시 최대 거리, 가림, 질량 제한을 검사

2. **상태 흐름**  
   - `비활성 → 대상 탐색 → 잡기 → 이동 → 놓기 또는 취소`

3. **제어 제한**  
   - 조작 중에는 다른 대상을 선택하지 못함  
   - 취소·사망·재시작 시 물리 연결을 해제

4. **회전**  
   - 직접 회전은 [결정 기록](../../Planning/DECISIONS.md)의 D-004가 확정될 때까지 요구하지 않음

# 구성 요소

- **상태 머신**  
  - 비활성, 대상 탐색, 잡기, 이동, 놓기/취소 상태

- **물리 연결**  
  - 잡기 시 물체와 플레이어 사이에 고정 또는 매듭 연결

- **제약 파라미터**  
  - 탐색 거리  
  - 잡기 거리  
  - 이동 속도  
  - 질량 제한  
  - 선형 감쇠  
  - 각도 감쇠  
  - 충돌 반발

- **조정값**  
  - 탐색 거리, 잡기 거리, 이동 속도, 질량 제한, 선형·각 감쇠, 충돌 반발을 기록하고 레벨별로 임의 하드코딩하지 않는다.
