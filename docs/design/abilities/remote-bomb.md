# 요약
폭탄 하나를 원하는 위치에 생성하고, 원할 때 기폭해 물리 반응 또는 파괴를 일으키는 능력.

# 목표 및 의도
- 폭탄 종류 추가, 연쇄 폭발, 원작 특정 장치 복제는 범위에서 제외.

# 게임 규칙
- 동시에 한 개만 유지한다.
- 생성과 기폭의 입력 상태를 명확히 구분한다.
- 폭발 대상은 물리 힘, 피해, 파괴 반응을 각각 선택적으로 받을 수 있다.
- 플레이어의 넉백·피해는 사당 진행을 막지 않도록 제한한다.
- 재시작과 사망 시 활성 폭탄을 제거한다.
