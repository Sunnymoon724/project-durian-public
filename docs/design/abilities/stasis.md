# 요약
물체를 잠시 멈추고, 정지 중 받은 힘을 축적해 해제할 때 예측 가능한 방향으로 발사하는 능력이다.

# 목표 및 의도
확인 필요

# 게임 규칙
- 정지 가능한 대상만 선택한다.
- 지속 시간과 최대 축적 힘을 제한한다.
- 축적 방향·강도를 시각적으로 전달한다.
- 해제 시 한 번만 힘을 적용하고, 목표 판정과 물리 충돌이 안정적이어야 한다.
- 재시작 또는 대상 파괴 시 정지 상태를 해제한다.

# 구성 요소
확인 필요

# 관련 문서
확인 필요

# 변경 이력
- 능력 상세 규칙 및 검증 항목 생성.
- 정지, 타격, 해제, 목표 충돌, 실패 후 재시작 시 힘 누적과 상태 해제 확인 절차 명시.
