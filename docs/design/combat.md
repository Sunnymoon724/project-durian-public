# 요약
전투 사당 하나에서 적의 공격을 읽고 가드, 패링, 회피 중 적절한 대응을 선택하는 기본 전투 시스템을 정의한다.

# 목표 및 의도
- 공격을 읽고 상황에 맞는 적절한 대응을 선택하는 기본 전투를 제공한다.

# 게임 규칙
- 적은 한 종류, 전투 공간은 한 곳으로 제한한다.
- 복수 적 조합, 장비, 콤보 확장, 저장은 범위에서 제외한다.

## 플레이어 행동
| 행동 | 목적 | 검증 기준 |
| --- | --- | --- |
| 공격 | 적에게 피해 | 적 체력과 피격 피드백 반영 |
| 가드 | 피해 완화 또는 차단 | 전방 공격에만 적용 |
| 패링 | 정확한 타이밍의 반격 기회 | 성공·실패가 명확히 구분 |
| 회피 | 위험 위치 이탈 | 무적 시간은 최소 범위로 제한 |

## 전투 메커니즘
- 패링 성공 보상은 적의 짧은 경직처럼 간단한 상태로 시작한다.
