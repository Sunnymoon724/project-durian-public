# 게임 규칙
## 게임 진행 흐름

### 기본 루프
```text
사당 진입 → 공간 관찰 → 능력 선택 → 대상 조작 또는 전투
  → 장치 상태 변화 → 목표 도달 또는 적 처치 → 클리어
  → 다음 사당 선택 또는 재시작
```

### 플레이 규칙
- 사당은 하나의 핵심 기믹을 먼저 보여주고, 짧은 응용으로 이해를 확인한다.
- 목표와 핵심 대상은 같은 화면 또는 짧은 이동 안에서 관계를 추론할 수 있어야 한다.
- 실패는 사망, 오브젝트 유실 또는 막힘으로 정의하며, `Backspace` 재시작으로 복구한다.
- 클리어는 한 번만 처리하며, 입력·물리 연결·UI 상태를 안전하게 종료한다.

## 사당 상태

| 상태 | 진입 조건 | 종료 조건 |
| --- | --- | --- |
| 준비 | 맵 로드 완료 | 플레이어 입력 허용 |
| 진행 | 플레이어가 조작 가능 | 클리어 또는 재시작 |
| 클리어 | 목표 달성 | 결과 확인 또는 다음 사당 |
| 재시작 | 재시작 입력 또는 복구 필요 | 초기 상태 로드 완료 |
