# 요약
Project Durian의 플레이어 조작 체계 및 입력 매핑 명세입니다.

# 목표 및 의도
- 직관적인 능력 선택 및 활용 인터페이스 제공
- 디버깅을 위한 에디터 전용 입력 지원

# 게임 규칙

## 기본 조작

| 동작 | 키보드·마우스 | 비고 |
| --- | --- | --- |
| 이동 | `W`, `A`, `S`, `D` | Unreal Third Person 기본 이동 |
| 카메라 | 마우스 이동 | 캐릭터 주변 카메라 회전 |
| 점프 | `Space` | Unreal Third Person 기본 점프 |
| 레벨 재시작 | `Backspace` | 현재 레벨과 퍼즐 상태 전체 초기화 |

## 능력 선택

| 동작 | 입력 | 비고 |
| --- | --- | --- |
| 선택창 열기 | `Q` 누르기 | 누르는 동안 네 능력 표시 |
| 선택 후보 변경 | `Q`를 누른 상태에서 마우스 이동 | 방향에 해당하는 능력 강조 |
| 선택 확정 | `Q` 놓기 | 강조된 능력을 활성 능력으로 지정 |
| 능력 사용 | 마우스 왼쪽 버튼 | 선택한 능력의 기본 동작 |
| 능력 취소 | 마우스 오른쪽 버튼 | 현재 조준 또는 조작 상태 취소 |

선택 가능한 능력은 자력, 원격 폭탄, 얼음 생성, 시간 정지입니다.

## 자력

| 동작 | 입력 | 비고 |
| --- | --- | --- |
| 대상 조준 | 화면 중앙 | 유효한 금속 물체만 강조 |
| 잡기 | 마우스 왼쪽 버튼 | 강조된 물체 조작 시작 |
| 놓기 | 마우스 왼쪽 버튼 | 조작 중인 물체 해제 |
| 거리 조절 | 마우스 휠 | 최소·최대 거리 안에서 조절 |
| 취소 | 마우스 오른쪽 버튼 | 물체를 놓고 자력 조작 종료 |

물체 직접 회전은 아직 확정되지 않았습니다. 결정 전 기준은 별도 회전 입력을 제공하지 않고, 회전 없이 풀 수 있도록 레벨을 설계하는 것입니다. 자세한 선택지는 [결정 기록](../Planning/DECISIONS.md)을 따릅니다.

## 에디터 디버그 전용

| 능력 | 키 |
| --- | --- |
| 자력 | `1` |
| 원격 폭탄 | `2` |
| 얼음 생성 | `3` |
| 시간 정지 | `4` |

숫자키는 능력 선택창을 거치지 않고 즉시 선택합니다. 에디터 테스트에서만 활성화하며 패키징 빌드에서는 비활성화합니다.
