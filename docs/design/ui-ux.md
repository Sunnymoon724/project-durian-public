# 요약
Project Durian의 UI 및 UX 설계 원칙과 필수 구성 요소를 정의합니다.

# 목표 및 의도
- 조작 설명보다 레벨 배치와 상태 피드백을 우선시함.
- 프롬프트를 맥락에 맞게 노출하여 시각적 혼란을 최소화함.
- 직관적인 선택창 구성 및 접근성 확보.

# 게임 규칙
- 프롬프트는 필요한 순간에만 표시하고 수행 후 즉시 제거.
- 선택창은 게임 화면을 가리지 않으며 마우스 방향과 후보 간의 관계를 즉시 인지 가능하게 설계.
- 개발용 디버그 정보는 패키징 빌드에서 제외.

# 구성 요소
## 필수 UI
- 현재 능력 아이콘 또는 이름
- `Q` 능력 선택창과 선택 후보 강조
- 대상 선택 가능·불가능 표시
- 상호작용 중 취소 안내
- 사당 클리어와 재시작 안내

## 접근성
- 텍스트와 아이콘 병행 사용.
- 성공·실패·위험 정보를 색상 외에 형태, 움직임, 소리로 구분.
- UI 문구는 행동 중심의 짧은 문장으로 작성 (예: `금속 블록 잡기`, `Backspace: 재시작`).
