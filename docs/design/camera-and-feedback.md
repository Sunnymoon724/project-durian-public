# 요약
게임 내 카메라 조작 방식과 상호작용 피드백의 우선순위 및 구현 원칙을 정의한다.

# 목표 및 의도
사용자에게 명확한 시각적/청각적 피드백을 제공하여 현재 상태를 인지시키고, 퍼즐 해결 과정에서 스스로 정답을 찾도록 유도한다.

# 게임 규칙
- **카메라**:
    - 기본적으로 3인칭 추적 카메라를 사용한다.
    - 능력 대상 탐색은 화면 중앙 Trace를 기준으로 한다.
    - 퍼즐의 정답을 자동으로 보여주지 않으며, 핵심 대상·장치·목표를 한 시야에 배치하는 방식으로 설계한다.
- **피드백**:
    - 상태별로 최소 두 종류의 피드백을 혼합하여 제공한다. (예: 강조 색과 윤곽선, 압력판 높이 변화와 발광 등)
    - 색상 변화만으로 상태를 구분하지 않는다.

# 구성 요소
## 피드백 우선순위
1. 지금 조작할 수 있는 대상인가
2. 선택되었는가
3. 능력이 실제로 실행 중인가
4. 장치 조건이 충족되었는가
5. 목표를 달성했는가
