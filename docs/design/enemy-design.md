# 목표 및 의도

전투 사당의 적은 플레이어가 가드·패링·회피를 모두 사용하도록 단순하고 읽기 쉬운 공격 패턴을 제공한다.

# 게임 규칙

## 상태

```
대기 → 추적 → 공격 예고 → 공격 → 회복
                  └→ 패링됨 → 경직 → 추적
피격 → 회복 또는 사망
```

## 최소 패턴

- 짧은 근접 공격: 가드 또는 회피 학습
- 명확한 예고가 있는 강한 공격: 패링 학습
- 공격 뒤 회복 시간: 플레이어 반격 기회

적의 애니메이션·사운드·VFX는 공격 판정과 같은 타이밍을 전달해야 한다. 보이지 않는 즉발 공격은 사용하지 않는다.
