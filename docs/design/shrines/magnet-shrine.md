 # 자력 사당 수직 슬라이스

## 목적

자력으로 금속 물체를 조작하는 감각을 검증하고, 이후 모든 사당이 재사용할 대상 탐색, 물리 오브젝트, 진행 장치, 클리어와 재시작 흐름을 완성한다.

참고 대상은 `Toh Yahsa Shrine — Buried Secrets`지만 고유 명칭, 맵 구조, 구체적인 해법, 아트와 사운드는 사용하지 않는다.

## 플레이 흐름

```text
시작
  → 눈에 잘 띄는 금속 블록 발견
  → 블록을 옮겨 막힌 통로 개방
  → 다음 공간에서 압력판과 닫힌 문 발견
  → 블록을 압력판에 배치
  → 문 통과
  → 목표 지점 도착과 클리어
```

## 콘텐츠 범위

- 목표 시간: 2~4분
- 주요 공간: 최대 2개
- 자력 물체: 1~2개
- 압력판: 1개
- 문: 1개
