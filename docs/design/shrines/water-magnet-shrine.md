# 요약
기존 자력과 수면 시스템을 조합해 물 위의 금속 오브젝트를 이동 경로 또는 발판으로 활용한다.

# 목표 및 의도
- 새 핵심 능력을 추가하지 않는다.
- 자력 사당과 얼음 사당에서 배운 조작만 요구한다.
- 물리 오브젝트가 물 위에서 불안정해도 재시작으로 복구 가능해야 한다.

# 게임 규칙
수면 너머 목표 확인 → 물 위 금속 오브젝트 발견 → 자력으로 위치 조정 → 이동 경로 확보 → 목표 도달.
