# 요약
적 한 종류를 상대로 공격, 가드, 패링, 회피의 기본 대응을 모두 사용하는 사당.

# 목표 및 의도
- 플레이어가 전투의 기본 대응(공격, 가드, 패링, 회피)을 학습하고 검증할 수 있는 환경 제공.

# 게임 규칙
1. 안전한 시작 공간에서 시작한다.
2. 적의 공격 예고를 관찰하고 대응한다.
3. 가드와 회피를 학습한다.
4. 패링 기회를 활용하여 적을 처치한다.
5. 적 처치 시 사당 클리어.

# 구성 요소
- 적: 특정 종류 1종.
- 기믹: 가드, 패링, 회피가 필요한 공격 패턴.

# 관련 문서
확인 필요

# 변경 이력
- 모든 방어 행동이 실제 공격에서 검증되어야 함.
- 패링 성공과 실패의 차이가 명확해야 함.
- 적 사망 뒤 클리어가 중복 발생하지 않아야 함.
- 플레이어 사망 또는 재시작 뒤 적 상태가 정상 복구되어야 함.
