# 요약
정지한 물체에 힘을 축적하고 해제해 먼 목표를 맞히거나 길을 연다.

# 목표 및 의도
- 축적 방향과 크기를 플레이어가 예측할 수 있다.
- 실패한 물체가 유실되지 않거나 재시작으로 복구된다.
- 목표 판정이 물리 프레임 차이로 누락되지 않는다.

# 게임 규칙
움직이는 물체와 목표를 관찰 → 시간 정지 → 힘 축적 방향 확인 → 해제 → 목표 판정 → 클리어.
