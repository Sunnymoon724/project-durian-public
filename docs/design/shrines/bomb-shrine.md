# 요약
폭탄의 생성 위치와 기폭 시점을 이용해 장애물 또는 물리 오브젝트 상태를 변경하는 사당.

# 목표 및 의도
- 폭탄 한 종류를 활용함.
- 파괴 대상 또는 밀어낼 대상 1~2종을 배치함.
- 원작의 특정 맵, 구멍, 발사 장치 해법은 사용하지 않음.

# 게임 규칙
- 폭발 반경이 예측 가능해야 함.
- 플레이어가 의도치 않게 진행 불가 위치로 밀려나지 않아야 함.
- 폭발 뒤에도 목표 상태가 안정적으로 유지되어야 함.
