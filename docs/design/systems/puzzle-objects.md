# 요약
Project Durian의 퍼즐 오브젝트 설계 및 운영 원칙을 정의합니다.

# 목표 및 의도
퍼즐 오브젝트는 초기 상태를 복구할 수 있어야 하며, 장치와 직접 강하게 결합하지 않습니다. 오브젝트는 상태나 이벤트를 발행하고, 레벨에서 압력판·문·목표와 연결합니다.

# 게임 규칙
* 압력판 신호가 짧게 변해도 문이 반복해서 떨리지 않도록 안정화 시간을 둡니다.

# 구성 요소

| 오브젝트 | 책임 | 핵심 상태 |
| --- | --- | --- |
| 물리 블록 | 이동·충돌·능력 대상 | 초기 Transform, 질량, 태그 |
| 압력판 | 대상 또는 무게 감지 | 활성, 안정화 시간 |
| 문 | 통과 경로 개방 | 열림, 닫힘, 끼임 방지 |
| 목표 볼륨 | 클리어 판정 | 완료 여부 |
| 파괴 대상 | 폭발·피해 반응 | 온전함, 파괴됨 |
