# 요약
`Backspace` 키를 입력하여 현재 레벨 전체를 초기 상태로 불러오는 시스템입니다.

# 목표 및 의도
진행 차단 상황 발생 시, 게임을 오류 없이 복구하기 위한 최후의 수단으로 설계되었습니다. 개별 오브젝트 복구는 이번 범위에 포함하지 않습니다.

# 게임 규칙
- `Backspace` 키 입력 시 현재 레벨을 전체 재로딩합니다.
- 어떤 상태에서 호출하더라도 오류 없이 재시작이 완료되어야 합니다.

# 구성 요소

## 재시작 전 정리
- 자력 Handle 또는 동등한 물리 연결 해제
- 능력 조준 및 선택 강조 제거
- 보류 중인 타이머 및 클리어 이벤트 취소 또는 무효화
- UI 입력 상태와 프롬프트 해제

## 재시작 후 확인
- 플레이어 위치 및 체력
- 물리 오브젝트 Transform 및 물리 상태
- 압력판, 문, 목표 상태
- 적의 생존 및 AI 상태
- 현재 능력과 입력 컨텍스트
