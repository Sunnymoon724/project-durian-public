# 요약
능력이 사용할 수 있는 대상을 카메라 중심에서 찾고, 유효성·강조·실행을 일관된 규칙으로 처리한다.

# 목표 및 의도
확인 필요

# 게임 규칙
1. 능력이 대상 탐색 가능한 상태인지 확인한다.
2. 카메라 중앙에서 최대 거리까지 Trace한다.
3. 충돌한 대상의 태그·컴포넌트·상태를 검사한다.
4. 가림, 거리, 이미 조작 중인 대상 여부를 검사한다.
5. 후보를 강조하고 사용 입력을 기다린다.

후보가 바뀌거나 유효성을 잃으면 이전 강조를 즉시 해제한다. 실행 중에는 후보를 바꾸지 않는다.
