# 요약
본 문서는 Project Durian의 피해(Damage) 및 체력(Health) 시스템의 설계 원칙과 게임 규칙을 정의합니다.

# 목표 및 의도
- 폭탄 사당과 전투 사당에 피해 및 체력 시스템을 적용합니다.
- 초기 퍼즐 사당에는 불필요한 피해 시스템을 배제합니다.
- 퍼즐 물체에 전투 규칙을 강제하지 않으며, 플레이어와 적의 수치는 데이터를 통해 조정합니다.

# 게임 규칙
- **피해 이벤트 전달**: 공격자, 대상, 피해량, 방향, 유형 정보를 포함합니다.
- **상태 검사**: 대상은 피해 처리 전 무적, 가드, 패링, 사망 상태 여부를 먼저 확인합니다.
- **피해 처리**: 유효한 피해가 확정되면 체력 감소, 피격 피드백, 넉백을 발생시킵니다.
- **사망 처리**: 체력이 0이 될 경우 사망 또는 사당 재시작 흐름으로 전환합니다.
