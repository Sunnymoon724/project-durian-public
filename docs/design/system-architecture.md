## 목적

사당별로 기능을 복제하지 않고, 공통 시스템에 능력과 레벨 규칙을 조합해 콘텐츠를 만든다. 아래 이름은 책임을 설명하는 개념명이며 실제 C++ 클래스명은 구현 현황 조사 뒤 연결한다.

## 시스템 구성

```text
플레이어 입력
  → 능력 선택·상태
    → 대상 탐색·강조
      → 능력별 실행
        → 퍼즐 오브젝트·진행 장치
          → 목표 판정·클리어

레벨 재시작
  └→ 플레이어, 능력, 물리 오브젝트, 장치 상태 복구
```
