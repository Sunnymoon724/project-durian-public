# 요약
플레이어의 상태 모델과 상태 간 우선순위 규칙을 정의합니다.

# 목표 및 의도
- 플레이어의 액션 상태를 체계화하여 관리합니다.
- 상태 전환 시 이전 상태의 잔류 현상을 방지하고 일관된 규칙을 적용합니다.

# 게임 규칙

## 상태 모델
```text
이동 가능
  ├─ 능력 선택 중
  ├─ 능력 조준 중
  ├─ 능력 실행 중
  ├─ 전투 행동 중
  └─ 피격·사망
```

- 능력 선택 중에는 이동을 유지할지 정지할지 UI 구현 전에 결정합니다.
- 능력 실행 중인 물리 대상은 하나만 유지합니다.
- 피격, 사망, 재시작, 사당 클리어는 모든 능력 실행 상태를 해제합니다.
- 상태 전환은 입력 해제나 레벨 전환 뒤에도 남지 않아야 합니다.

## 우선순위
`사망·재시작` > `클리어` > `피격` > `능력 실행` > `능력 선택` > `이동` 순서로 기존 상태를 취소합니다.
