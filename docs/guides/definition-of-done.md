# 작업 절차
## 기능
- 정상 경로와 취소·재시작 경로가 동작한다.
- 관련 문서와 입력이 실제 동작과 일치한다.
- 알려진 P0·P1 문제가 없다.

## 사당
- 입장부터 클리어까지 5회 연속 진행한다.
- 목표와 핵심 조작을 외부 플레이어가 이해한다.
- 목표 시간 2~4분을 기록한다.

## 문서
- 한 문서의 책임이 명확하다.
- 다른 기준 문서와 중복·충돌하지 않는다.
- 내부 링크와 실제 경로가 유효하다.
