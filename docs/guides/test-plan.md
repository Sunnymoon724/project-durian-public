# 작업 절차

## 테스트 단계

### 기능 테스트
각 공통 시스템과 능력을 독립 테스트 맵에서 확인한다.

- 정상 입력
- 입력 취소
- 유효하지 않은 대상
- 거리 이탈과 벽 가림
- 사망 또는 레벨 재시작
- 반복 실행 후 남는 상태

### 사당 테스트
각 사당은 다음 경로를 확인한다.

- 처음부터 클리어까지 정상 경로
- 오브젝트 유실·낙하·끼임
- 능력 사용 중 취소
- 퍼즐 도중 레벨 재시작
- 클리어 이벤트 중복 발생
- 목표 플레이 시간 2~4분

### 통합 테스트
- 사당 간 이동 또는 선택
- 다른 사당을 플레이한 뒤 입력과 능력 상태 잔존 여부
- 6개 사당 연속 클리어
- Development 빌드와 Shipping 빌드의 차이

## 수직 슬라이스 체크리스트
- [ ] 자력 모드가 아닐 때 금속 물체를 선택할 수 없다.
- [ ] 벽 뒤와 최대 거리 밖 물체를 선택할 수 없다.
- [ ] 후보가 바뀌면 이전 강조가 해제된다.
- [ ] 조작 중인 물체가 임의로 다른 대상으로 바뀌지 않는다.
- [ ] 잡기, 놓기, 취소를 반복해도 물리가 정상이다.
- [ ] 벽과 천장에 닿아도 심하게 떨리거나 관통하지 않는다.
- [ ] 압력판 신호가 불필요하게 깜빡이지 않는다.
- [ ] 문이 플레이어나 블록을 끼우지 않는다.
- [ ] 조작 중 재시작해도 오류나 연결 상태가 남지 않는다.
- [ ] 5회 연속으로 시작부터 클리어까지 진행할 수 있다.

## 외부 플레이테스트 기록
각 세션에서 아래 항목을 기록한다.

| 항목 | 기록 내용 |
| --- | --- |
| 플레이 시간 | 입장부터 클리어까지 소요 시간 |
| 첫 행동 | 플레이어가 처음 시도한 행동 |
| 막힌 지점 | 10초 이상 진행하지 못한 위치와 이유 |
| 재시작 | 횟수와 원인 |
| 조작 혼란 | 잘못 이해한 입력 또는 피드백 |
| 진행 차단 | 복구 불가능하거나 재시작이 필요했던 문제 |

# 문제 해결

## 문제 우선순위
| 우선순위 | 기준 |
| --- | --- |
| P0 | 실행, 입장, 클리어 또는 재시작 불가 |
| P1 | 정상 플레이에서 진행 차단 또는 높은 빈도의 물리 실패 |
| P2 | 조작 혼란, 잘못된 피드백, 눈에 띄는 사용성 문제 |
| P3 | 장식, 경미한 시각 문제와 선택적 개선 |

마일스톤 종료 전 P0는 0건이어야 하며, 릴리스 전 P1은 해결하거나 알려진 문제로 명확히 기록한다.
