# 목적
작업 보드 작성 시 일관된 형식을 유지하여 효율적인 작업 관리를 도모한다.

# 사전 조건
확인 필요

# 작업 절차
작업 항목 작성 시 다음 규칙을 준수한다.

1. **작업 단위 세분화**: 작업 하나당 하나의 검증 가능한 결과를 가지도록 한다. “자력 구현”과 같이 범위가 넓은 항목은 “자력 대상 Trace에서 가림 대상 제외”와 같이 구체적으로 쪼갠다.
2. **작업 항목 형식 준수**:
    - 목적: 왜 필요한가
    - 범위: 수정할 시스템·맵·에셋
    - 완료 기준: 플레이 또는 테스트로 확인할 결과
    - 제외 범위: 이번 작업에서 하지 않을 것
    - 검증: 수행할 테스트
3. **버그 항목**: 반드시 재현 단계와 우선순위를 포함한다.
