# 범위

## 이번 릴리스에 포함

### 콘텐츠

- 퍼즐 사당 5개
- 전투 사당 1개
- 사당별 목표 플레이 시간 2~4분
- 사당별 핵심 기믹 1개와 짧은 응용 1개
- 입장, 플레이, 클리어, 레벨 재시작 흐름

### 플레이어 기능

- 이동, 카메라, 점프
- 능력 선택과 사용 취소
- 자력, 얼음 생성, 시간 정지, 원격 폭탄
- 공격, 가드, 패링, 회피
- 피해, 사망, 재시작

### 공통 퍼즐 기능

- 대상 탐색과 선택 강조
- 물리 오브젝트와 초기 상태 복구
- 스위치, 압력판, 문, 목표 판정
- 조작 안내와 성공·실패 피드백

## 명시적으로 제외

- 수영
- 인벤토리
- 무기 내구도
- 스태미나
- 복수 적 종류와 복잡한 적 조합
- 복잡한 저장·불러오기
- 여러 자력 물체의 동시 조작
- 복수 종류의 원격 폭탄
- 대규모 시네마틱과 고품질 사당 아트
- 원작의 고유 명칭, 공간 배치, 에셋, 사운드 또는 퍼즐 해법 복제

## 콘텐츠 제한

- 얼음 블록은 동시에 1~2개까지만 유지한다.
- 적은 한 종류로 제한한다.
- 각 사당은 최대 2개의 주요 공간으로 구성한다.
- 퍼즐 실패는 레벨 전체 재시작으로 복구 가능해야 한다.
- 새 기믹은 기존 공통 시스템으로 설명할 수 있을 때만 추가한다.

## 일정이 부족할 때 줄이는 순서

1. 장식과 연출 품질
2. 보조 퍼즐과 추가 방
3. 오브젝트 종류와 변형
4. 사당 내부 이동 거리

핵심 능력, 최소 1개의 학습 구간, 클리어 흐름과 진행 차단 방지는 유지한다. 사당 수 유지 여부는 일정 재산정 후 [결정 기록](DECISIONS.md)에서 다시 확정한다.

## 변경 관리

새 기능을 범위에 넣기 전 아래 질문에 모두 답한다.

- 어떤 플레이 경험을 개선하는가?
- 기존 사당 또는 시스템을 재사용하는가?
- 어떤 마일스톤과 완료 기준이 바뀌는가?
- 같은 기간 안에 무엇을 제외할 것인가?
