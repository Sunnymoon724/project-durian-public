# 요약
공통 시스템을 먼저 검증하고, 자력 사당을 수직 슬라이스로 완성한 뒤, 검증된 시스템을 조합해 나머지 사당을 확장한다.

# 목표
공통 시스템 검증, 자력 사당 수직 슬라이스 완성, 공통 시스템 조합을 통한 사당 확장.

# 현재 상태
구현 현황은 코드와 Unreal Editor에서 대조되지 않았으므로, 모든 작업 상태는 확인 필요.

# 범위
- 범위 및 조작 확정
- 공통 플레이 기반
- 자력 사당 수직 슬라이스
- 얼음/수면 사당
- 기존 능력 조합 사당
- 시간 정지 사당
- 폭탄 사당
- 전투 사당
- 통합 테스트 및 출시

# 마일스톤

## 1. 기준선 확인
- 현재 C++ 클래스, Blueprint, 입력 설정과 레벨 목록 조사.
- 기존 구현과 공통 시스템 목록 연결.
- 플레이 가능 기능과 미구현 기능 구분.
- DECISIONS.md의 미결정 항목 확정.
- 완료 기준: 각 기능에 상태(완료, 부분 구현, 미구현, 폐기 후보) 부여.

## 2. 공통 기반
- 플레이어 이동, 카메라, 점프와 입력 컨텍스트.
- 능력 선택과 공통 상태 전환.
- 카메라 중심 대상 탐색과 선택 강조.
- 퍼즐 오브젝트 초기 상태 저장/복구.
- 압력판, 문, 클리어 목표 및 레벨 재시작.
- 완료 기준: 테스트 맵에서 입력, 대상 선택, 문 개방, 클리어/재시작 반복 검증.

## 3. 자력 사당 수직 슬라이스
- 자력 대상 식별.
- 물리 기반 잡기, 이동, 거리 조절, 놓기.
- 튜토리얼 공간과 압력판 퍼즐 공간.
- 최소 UI와 피드백.
- 5회 연속 클리어 테스트.

## 4. 퍼즐 사당 확장
- 얼음/수면 기능(Keh Namut).
- 자력과 수면 결합(Daka Tuss).
- 물체 정지와 힘 축적(Mirro Shaz).
- 원격 폭탄과 물리 반응(Ya Naga).

## 5. 전투 사당
- 공격, 가드, 패링, 회피.
- 피해, 넉백, 체력, 사망/재시작.
- 적 AI, 전투 시작/승리/클리어 흐름.

## 6. 통합과 출시
- 6개 사당 연속 플레이.
- 입력 안내와 피드백 통일.
- 진행 차단, 물리 불안정, 패키징 오류 수정.
- 외부 플레이테스트 및 난이도 조정.
- Shipping 빌드 및 결과물 준비.

# 의존성 및 위험 요소

| 위험 | 영향 | 대응 |
| --- | --- | --- |
| 물리 오브젝트 떨림/관통 | 퍼즐 진행 차단 | 수직 슬라이스에서 이동 속도, 질량, 감쇠, 충돌 조기 검증 |
| 능력별 별도 구조 생성 | 유지보수 및 일정 악화 | 공통 인터페이스 사용 |
| 사당 6개 동시 진행 | 완료 기준 불명확 | 한 사당 완료 후 확장 |
| 조작 명세 변경 | 작업 재수행 | 구현 전 결정 기록 확정 |
| 테스트 후반 집중 | 치명적 버그 누적 | 각 사당 반복 클리어 조건화 |
