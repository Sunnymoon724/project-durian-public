# 요약
Project Durian은 Unreal Engine 5.8과 C++를 기반으로 제작하는 짧은 3D 퍼즐 액션 데모입니다. 플레이어는 네 가지 물리 기반 능력을 익히고 조합해 5개의 퍼즐 사당과 1개의 전투 사당을 완료하게 됩니다.

# 목표
- 플레이어가 별도의 긴 설명 없이 공간과 오브젝트의 관계를 관찰해 해법을 발견하게 함
- 능력을 사용했을 때 대상 선택, 물리 반응, 성공 여부가 즉시 이해되도록 함
- 각 사당은 2~4분 안에 하나의 핵심 아이디어를 배우고 응용하도록 구성
- 실패하더라도 빠르게 초기화하고 다시 시도할 수 있도록 함
- 공통 퍼즐 시스템 구축 후 사당별 기능 확장
- 자력, 얼음 생성, 시간 정지, 원격 폭탄의 핵심 상호작용 구현
- 근접 공격, 가드, 패링, 회피를 사용하는 전투 사당 완성
- 총 6개 사당을 포함한 배포 빌드 제공

# 의존성 및 위험 요소
- 성공 기준:
    - 6개 사당의 입장, 목표 달성, 클리어 가능
    - 진행 차단 문제 발생 시 레벨 재시작으로 정상 복구 가능
    - 처음 플레이하는 사람이 핵심 대상과 목표를 인지 가능
    - Development 및 Shipping 빌드에서 기본 진행이 동일하게 동작
    - 명칭, 공간 구성, 에셋, 사운드, 퍼즐 해법은 독자적으로 제작
- 제작 원칙:
    - C++는 재사용 가능한 규칙과 시스템 담당
    - Blueprint는 레벨 배치, 데이터 설정, 수치 조정 및 시각 피드백 담당
    - 회색 박스 단계에서 재미와 안정성을 검증 후 아트/연출 보강
    - 참고 작품은 기믹 연구에만 활용하며 표현/해법 복제 금지
