# 요약
Project Durian의 개발 마일스톤별 달성 현황을 관리하는 문서입니다. 실제 플레이 및 빌드 검증 결과를 기준으로 상태를 업데이트합니다.

# 목표
- M0부터 M5까지 각 마일스톤의 종료 조건을 충족하고 검증 데이터를 확보한다.

# 현재 상태
본 문서는 실제 플레이·빌드 검증을 기준으로 갱신됩니다. 문서 작성이나 코드 존재만으로는 완료 처리하지 않습니다.

# 범위
- M0 기준선 확정
- M1 자력 수직 슬라이스
- M2 퍼즐 코어
- M3 콘텐츠 완성
- M4 외부 테스트
- M5 릴리스

# 마일스톤

| 마일스톤 | 상태 | 근거 | 다음 행동 |
| --- | --- | --- | --- |
| M0 기준선 확정 | 확인 필요 | 현재 코드·Content 현황 대조 전 | 클래스, 맵, 입력 자산 조사 |
| M1 자력 수직 슬라이스 | 미착수 | 자력 기능 플레이 검증 없음 | 공통 기반과 자력 사당 구현 |
| M2 퍼즐 코어 | 미착수 | 사당 구현 검증 없음 | M1 완료 뒤 착수 |
| M3 콘텐츠 완성 | 미착수 | 사당 구현 검증 없음 | M2 완료 뒤 착수 |
| M4 외부 테스트 | 미착수 | 테스트 기록 없음 | 플레이 가능 빌드 준비 |
| M5 릴리스 | 미착수 | 패키징 검증 없음 | 기능 동결 뒤 착수 |

## 상태 정의
- `미착수`: 구현 또는 검증을 시작하지 않음
- `진행 중`: 목표의 일부가 동작하나 종료 조건을 충족하지 않음
- `검증 대기`: 구현은 끝났으나 반복 플레이 또는 빌드 확인이 남음
- `완료`: 종료 조건과 테스트 증거가 있음
- `보류`: 범위 또는 일정 결정이 필요함
