# 현재 상태

## 확정
- **D-001 — 문서와 개발 저널 분리**  
  상태: 확정  
  결정: 설계·계획 문서는 `Documents/`, Docusaurus 개발 저널은 프로젝트 루트의 `Journal/`에서 관리한다.  
  이유: 제작 원본 문서와 게시용 사이트 소스의 책임을 분리한다.

## 현재 기준
- **D-002 — 기본 재시작 단위**  
  상태: 현재 기준  
  결정: `Backspace`로 현재 레벨 전체를 다시 불러온다.  
  제외: 개별 퍼즐 오브젝트만 초기화하는 일반 플레이 기능  
  재검토 조건: 레벨 로딩 시간이 반복 플레이를 방해할 경우

- **D-003 — 자력 사당의 문 동작**  
  상태: 현재 기준  
  결정: 금속 블록이 압력판 위에 있는 동안만 문을 연다.  
  안전 조건: 닫히는 문이 플레이어나 블록을 끼우지 않아야 한다.

## 미결정
- **D-004 — 자력 물체 직접 회전**  
  상태: 미결정  
  선택 A: 직접 회전을 제외하고 레벨 배치가 회전을 요구하지 않도록 설계한다.  
  선택 B: 별도 입력으로 일정 각도씩 회전시킨다.  
  영향: 조작 명세, 자력 구현량, 압력판과 통로 형태  
  초안 권장: 일정 보호를 위해 선택 A

- **D-005 — 게임패드 지원 범위**  
  상태: 미결정  
  선택 A: 키보드·마우스만 릴리스 필수 범위로 둔다.  
  선택 B: 게임패드까지 동일한 완료 기준으로 둔다.  
  영향: 입력 매핑, 능력 선택 UI, 테스트 조합

- **D-006 — 2026-10-15까지 사당 6개 유지**  
  상태: 구현 현황 확인 필요  
  기존 기준: 퍼즐 5개와 전투 1개를 유지한다.  
  확인 사항: 현재 구현 완료율, 1인 개발 가능 시간, 외부 테스트 가능 일정  
  영향: [로드맵](ROADMAP.md)의 M2~M5 기간과 [범위 정의](SCOPE.md)
