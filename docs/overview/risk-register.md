# 현재 상태
| ID | 위험 | 징후 | 대응 | 소유 시점 |
| --- | --- | --- | --- | --- |
| R-01 | 물리 오브젝트 불안정 | 떨림, 관통, 유실 | 자력 사당에서 질량·감쇠·충돌을 먼저 반복 검증 | M1 |
| R-02 | 범위 과다 | 사당 여러 개가 동시에 미완성 | 수직 슬라이스 완료 전 다음 사당 착수 금지 | 전 기간 |
| R-03 | 조작 혼란 | 첫 플레이어가 능력 선택에 멈춤 | UI 프롬프트와 관찰 가능한 튜토리얼 공간 보강 | M1~M4 |
| R-04 | 외부 리소스 권리 문제 | 출처·라이선스가 불명확 | 기본·직접 제작·명확한 라이선스 리소스만 사용 | 전 기간 |
| R-05 | 패키징 지연 | 에디터에서는 되나 빌드에서 실패 | M4 전에 Development 패키징 점검 | M4 |

* 매주 마일스톤 점검 시 위험 상태를 '열림', '완화', '해결'로 갱신함.
