# 개발일지

### 주요 작업 내용

**1. 프로젝트 기반 구축 및 시스템 구현**
* 언리얼 엔진 프로젝트 환경 설정 완료
* 퍼즐 시스템 기반 코드 구현

**2. 개발 로그 및 보고 자동화 워크플로우 고도화**
* 일일 및 주간 개발일지 생성 프로세스 자동화
* 개발일지 생성 프롬프트 개선 및 날짜 지정 옵션 추가
* Notion 연동 스크립트 추가 및 데이터베이스 기반 발행 방식으로 전환
* 개발일지 생성 워크플로우에 컨텐츠 삭제 단계 및 그룹 속성/값 설정 추가
* 미러링 제외 설정 및 환경변수 수정 등 워크플로우 최적화

**3. CI/CD 및 개발 환경 설정 최적화**
* CI 파이프라인 설정 업데이트
* .clangd 최적화

### 변경 사항 요약
* **프로젝트 설정 및 코드:** 언리얼 엔진 프로젝트 설정 파일 및 퍼즐 시스템 로직 추가
* **CI/CD 워크플로우:**
    * 일일/주간 개발 로그 자동 생성 로직 개선
    * Notion API 연동 및 데이터베이스 기반 로그 관리 구현
    * 워크플로우 내 날짜 로직, 속성 업데이트, 데이터 정리 단계 추가
* **설정 파일:** 프로젝트 개발 환경 최적화를 위한 .clangd 파일 수정 및 CI 파이프라인 설정 변경
